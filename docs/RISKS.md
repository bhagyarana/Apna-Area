# Top 10 Project Risks & Mitigations (`docs/RISKS.md`)

| # | Risk | Likelihood | Impact | Early Signal | Mitigation & Recovery | Owner |
|---|---|---|---|---|---|---|
| **R1** | **Live API room echo or venue noise causes NPC self-interruption or missed turns** | High | High | NPC cuts itself off on laptop speakers or VAD stays open in crowd noise | Enable `echoCancellation: true`, `noiseSuppression: true`, `autoGainControl: true` in `getUserMedia`; ship a 1-click **Push-to-talk (`Space`)** toggle and `audioStreamEnd: true` Hybrid VAD signal; test with and without headphones in `P3a`. | Neon Lead (`P3a`) |
| **R2** | **Kannada TTS/Live pronunciation or phrasing feels unnatural to a Bengaluru speaker** | Medium | High | Awkward literal translations or wrong register (`neevu` vs `neenu`) | Draft 30 phrases with Neon, review every phrase with Carbon for colloquial ORR polite register (`ಡಿ / ಅಣ್ಣ / ಅಕ್ಕ`), spot-check 10 phrases with a venue local, and gate behind `ENABLED_LANGUAGES` so `["en", "hi"]` is a 1-line fallback. | Carbon + Human (`P3c`) |
| **R3** | **Director (`gemini-4-neon`) latency exceeds 12 seconds or returns HTTP 503 under peak load** | Medium | High | Cold generation takes `> 10s` or throws `503 Model Overwhelmed` | Stream honest SSE progress chips within `300 ms` of click; set `thinking_level: "medium"` and concise candidate payloads; retry once with backoff then fall back to `gemini-4-hydrogen`, then labelled real session replay. | Neon Lead (`P2`) |
| **R4** | **Director references a `place_id` outside candidate list or repeats a place** | Low | Critical | Verifier catches non-enum or duplicate `placeId` | Lock `placeId` to a dynamic JSON Schema `enum` of verified 3 km candidates AND enforce `verifyWeekPlan` server-side before streaming `complete`. | Hydrogen Worker (`T2.2`) |
| **R5** | **Maps Browser Key blocked on Cloud Run preview or live URL due to HTTP referrer mismatch** | Medium | High | Grey map box or `RefererNotAllowedMapError` in browser console after `P0`/`P1` deploy | Allow `http://localhost:*` and `https://*.a.run.app/*` (or exact Cloud Run service wildcard) restricted strictly to Maps JS API; smoke test preview URL before promoting traffic. | Human + Lead (`P0`/`P1`) |
| **R6** | **`gcloud` or Cloud Run org policy blocks `--allow-unauthenticated`** | Low | Critical | First `gcloud run deploy` returns IAM policy error on `allUsers` | Run first deploy early in `P0` (`T0.6`) before feature work; if blocked by org policy, stop immediately and ask hackathon organisers rather than attempting workarounds. | Human + Lead (`P0`) |
| **R7** | **ASR transcript writes Kannada words in Roman or Devanagari script, confusing `gemini-decision-1` `phrase_attempt` rubric** | High | Medium | Player says `ondu kafi kodi` clearly, ASR transcribes phonetically, score returns `1` instead of `3` | Pass BOTH native script (`ಒಂದು ಕಾಫಿ ಕೊಡಿ`) AND phonetic transliteration (`ondu kafi kodi`) in `decisions.create` input AND accept Live tool signal `mark_phrase_attempt` alongside rubric score. | Neon Lead (`P3c`/`P4`) |
| **R8** | **Routes API `TRANSIT` mode returns empty routes or rejects `TRAFFIC_AWARE` parameter** | Medium | Low | 400 error when `routingPreference` is sent with `travelMode: "TRANSIT"` | Omit `routingPreference` on `TRANSIT` calls (verified in Routes v2 spec); render `"Direct metro/bus feeder varies; check BMTC"` gracefully when `TRANSIT` returns empty while still showing `DRIVE` and `TWO_WHEELER`. | Hydrogen Worker (`T5.1`) |
| **R9** | **Hackathon $40 quota drained by runaway loops, repeated Lyria/Nano Banana calls, or bots hitting public URL** | Low | Critical | Spend dashboard jumps `> $5` in a single phase | Generate Nano Banana portraits and Lyria MP3s ONCE via build scripts and commit static assets; rate-limit `/api/*` (`180/min/IP` reads, `30/min/IP` on all model/Maps `POST` routes); cap Live sessions at `90s`; cache Director, Routes, Summaries, and TTS per office/phrase. | Lead (`All Phases`) |
| **R10** | **Parallel worker agents overwrite shared files or break `main`** | Medium | High | Merge conflicts or unexpected diffs in `shared/types.ts` | Lead locks `shared/types.ts` interfaces BEFORE spawning workers; workers run in isolated `git worktree` checkouts with disjoint `Allowed Files` lists and pass `22-review-gate` before `--no-ff` merge. | Lead (`All Phases`) |
| **R11** | **3D WebGL shaders stall headless CI, SwiftShader software renderers, or low-power mobile GPUs (`phase/p8-3d-dusk`)** | High | Medium | Headless Playwright screenshot timeout (`> 30s`) or dropped frames on software WebGL | Detect hardware-accelerated WebGL2 (`WEBGL_debug_renderer_info` excluding `SwiftShader` / `llvmpipe`), verify `map.getMapCapabilities().isWebGLOverlayViewAvailable`, honour `prefers-reduced-motion`, auto-default mobile/headless to crisp 2D, and expose a 1-click `3D / 2D` topbar pill. | Lead (`P8`) |
| **R12** | **Three.js blows the `< 250 KB` initial JS gzip budget or 3D HUD obscures Google Maps attribution (`phase/p8-3d-dusk`)** | Medium | High | Initial entry bundle exceeds `250 KB` gzipped or bottom-left radar overlaps Google logo | Dynamically `import()` `OrrWebGlLayer` + `three` inside a dedicated Vite `vendor-three` chunk only when 3D activates (`188.1 KB` initial gzipped load untouched); anchor `RadarMinimap` (`bottom: 36px; left: 24px`) cleanly above Google attribution and retain `internalUsageAttributionIds={["gmp_git_agentskills_v1"]}`. | Lead (`P8`) |
